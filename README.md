
# Mario & Luigi Plumbing Services

A responsive website for a fictional plumbing company, inspired by the iconic Mario and Luigi characters.

The project was developed to present plumbing services through a friendly and engaging interface, providing visitors with an easy way to explore services and get in touch.

## Live Demo

[Visit the Website](https://lbdantas-creator.github.io/Mario-Luigi-Plumbing-Services/)

## Features

- Responsive layout for different screen sizes
- Homepage with company introduction
- Dedicated services page
- Interactive navigation
- Contact form with input mask
- WhatsApp contact integration
- Custom images and visual elements
- Background video and animations

## Technologies

- HTML5
- CSS3
- JavaScript
